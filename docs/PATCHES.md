# Patch reference

The release applies **86 release patches** to [TensorFold v0.6.6](https://github.com/ashhart/TensorFold/tree/v0.6.6),
commit `cb2ebf0540f42604e2759b2ddef497861e928248`. The 54 patches in `patches/miaai-lab/` are Mia's AI Lab's
recipe work, ported to v0.6.6. The 32 in `patches/aevonix/` are Aevonix Research's port and single-host work.
Patch 0023 is absent because upstream provides its reasoning-effort mapping. Patch 0037 was superseded
by upstream tokenization support in v0.6.5. See [CREDITS](../CREDITS.md) and [NOTICE](../NOTICE) for the
upstream work and third-party attribution retained in these patches.

See [the v0.6.6 rebase notes](PORT-v0.6.6.md) for the six regenerated patches and the priority merge,
[the current SHA256 table](PATCH-SHA256.md) for patch digests, and [the historical v0.6.5 port table](PORT-v0.6.5.md)
for earlier per-patch changes and upstream commit evidence. Mia's four regenerated patches change only
hunk line positions. Her patches remain hers. Measurements below describe the original patch studies.

The table uses **engine default -> release recipe default**; a value shown once is unchanged. Underscored
suffixes in a cell use the preceding variable's prefix. The recipe defaults are in [scripts/config.sh](../scripts/config.sh).
Effects are historical measurements, mostly from the q4 optimization sweeps at 250 W. Combined effects cannot
be added together and are not promises for FP8 dense or another host. A missing isolated measurement is stated
explicitly. Current production FP8 results and the dense-fidelity comparison are in the [README](../README.md).

**Exactness kinds:** `bits` preserves the tested target output at the same checkpoint, precision and prompt
reference; `drafts` changes proposals but target verification preserves replies; `reference` changes arithmetic
and needs its own output references and quality check; `structural` fixes layout, checks or coordination;
`diagnostic` changes observation; `feature` adds or changes API behavior. FP8 dense, q4 dense, FP8 KV and chunked
KDA are not bit-identical to the checkpoint's BF16 dense/BF16 KV/serial-KDA path. Exact draft and concurrency
checks do not establish equivalence to that path. Prompt kernels also use their own fixed, batch-invariant
arithmetic; the universal EXL3 route needs separate references.

Apply the series with `scripts/apply-patches.sh`, which merges both origin directories into global filename
order and refuses fuzz, offsets and leftover patch artifacts. It accepts an existing unpatched checkout or
installed package; with no target it clones the pinned upstream version. The image build uses the same script.

The optional numerical experiments `TF_GLM_EXPERT_PROMPT_KERNEL=k1q*` and `TF_GLM_LANE_PARTIALS=bf16` remain off.
The release also leaves streamed experts, split two-shot exchange, alternate index selection and diagnostic
profiles off. `TF_GLM_LANE_INPUTS=0` is required with FP8/BF16 dense; only the q4 recipe selects `kda`.
Keep first-use bit checks and fallback paths enabled when changing kernel choices. See [NOTES](NOTES.md)
for measurement limits and the byte-for-byte reproduction check.
